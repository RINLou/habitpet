# 星图冒险工作日志（2026-09-08）

## 本批目标

把“灵汐大陆”从背景文案推进为可重复游玩的 7 日轻冒险：每天完成真实投喂后走过一个章节节点，普通灵伴在自己的签名地点留下故事，毕业后仍可回访。

## 已完成

- `lib/adventure.js` 将原 3 节点扩展为 `first-starlight` 首章 7 日线：星海关口 → 赤曜荒原 → 月见潮汐 → 影桥回廊 → 翠雨林地 → 磐石隘口 → 星心圣所。
- 保留前三个旧节点 ID，历史状态可迁移；章节状态增加 `completedDays`、`chapterCompletedAt`、`chapterCompletions`，完成后允许回访已走过的节点。
- 8 只普通灵伴各有一个签名事件，只产生剧情反馈，不改变 XP、亲密度、连击、账本或战斗数值。
- 增加稳定哈希驱动的约 35% 低频随机奇遇。结果由“孩子 + 日期 + 节点”决定，刷新不会变化；只写故事记录，不发放数值奖励。
- 孩子端星图卡改为纵向路线图，显示 D1-D7、地图连线、当前/完成/锁定/回访状态和章节进度。
- 离线快照同步 7 日路线和章节状态；本批后 Service Worker 缓存版本升至 `hp-v18`。
- 野外 Boss 改为渐进式难度：单人 Lv1 约 0.70 倍属性、0.85 倍血量起步，之后每级小幅增加并封顶；联手模式保留多人血量优势。数值奖励规则不变。

## 设计约束

- 一天只探索一次，且必须先完成当天投喂；章节推进不靠付费、不扣资源、不制造失败惩罚。
- 随机事件只做气氛和世界观补强，不影响战力和养成平衡。
- 商业化仍为关闭状态，仅保留未来可挂接内容 ID/外观奖励的接口空间。

## 第一章叙事 MVP 追加（2026-09-08）

- 首章正式命名为 **《熄灭的七盏灵灯》**：七日路线从“节点故事列表”升级为连续主线，核心冲突是“浊气把一次中断误读为永远的失败”。
- 每个节点都有一段短剧情、一个旧星历线索和 2 个选择；终点提供 3 种无优劣的章节结语：星路守望者、灯下同行者、再启火种。
- 选择只影响对白、线索、相册和回访记录；不改变 XP、亲密度、等级、家庭奖励、账本或战斗属性。
- 8 只普通灵伴均补齐“初见—分歧—确认”三段关系入口，焰狼不再是唯一拥有角色弧线的灵伴。
- 相册扩展为节点记录、旧星历、灵伴来信和章节结语四层内容；家长摘要只显示近期故事进展与结语，不把剧情变成审核任务。
- 本地优先运行时同步第一章标题、节点分支和故事收藏字段，避免本地投喂后的离线投影把云端新剧情覆盖成旧版星图。
