# 星图冒险工作日志（2026-09-08）

## 本批目标

把“灵汐大陆”从背景文案推进为可重复游玩的 7 日轻冒险：每天完成真实投喂后走过一个章节节点，普通灵伴在自己的签名地点留下故事，毕业后仍可回访。

## 已完成

- `lib/adventure.js` 将原 3 节点扩展为 `first-starlight` 首章 7 日线：星海关口 → 赤曜荒原 → 月见潮汐 → 影桥回廊 → 翠雨林地 → 磐石隘口 → 星心圣所。
- 保留前三个旧节点 ID，历史状态可迁移；章节状态增加 `completedDays`、`chapterCompletedAt`、`chapterCompletions`，完成后允许回访已走过的节点。

## 设计约束

- 一天只探索一次，且必须先完成当天投喂；章节推进不靠付费、不扣资源、不制造失败惩罚。
- 随机事件只做气氛和世界观补强，不影响战力和养成平衡。
- 商业化仍为关闭状态，仅保留未来可挂接内容 ID/外观奖励的接口空间。
