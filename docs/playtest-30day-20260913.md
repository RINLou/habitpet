## 三、排期敏感性扫描（关键结论）

三章主线需要 **21 个有效日 + 2 天跨章等待 = 至少 23 个有效日**，而"有效日"要求当天既投喂又探索，高龄孩子联合概率不足：

| 排期 | 7-9 | 10-12 | 13-14 | 合计完成率 |
|---|---|---|---|---|
| 30 天 | 2/6 | 3/6 | 0/6 | **27.8%** |
| 45 天 | 5/6 | 6/6 | 3/6 | **77.8%** |
| 60 天 | 6/6 | 6/6 | 5/6 | **94.4%** |
| 75 天 | 6/6 | 6/6 | 6/6 | **100%** |

> **排期建议**：主线试玩周期改为 **45 天（主力档达标）/ 60 天（含 13-14 岁档）**。原方案 30 天只能验证第一章，三章数据会严重失真。

## 四、专项探针（真实代码行为，逐条可复跑）

### 1. 缺席分档（严格模式）——与 `engine.js:97-128` 完全一致

| 天数 | 事件 | 羁绊 |
|---|---|---|
| D1 | 最后投喂 | 100 |
| D2-D3 | 无 | 100 |
| **D4（满 3 天）** | `hungry` −10 | **90** |
| D5 | 无（一次性，不重复扣） | 90 |
| **D6（满 5 天）** | `faint` 进入休眠茧 | 90 |
| 唤醒后 | **免费**：不降级、不扣羁绊、不清收藏 | **90** |

默认温和模式下：全程只产生提醒，无休眠茧、无扣分（本轮 21 次提醒、0 次休眠）。

### 2. 跨章节奏

- D7 完成首章 → 当日可点亮第二章 ✅
- **当日出发第二章 → 返回当日结果（幂等，不推进）** ✅ 符合"同日不可借切章多刷"的设计
- 次日出发第二章 → 成功 ✅

### 3. 终章后回访任务 —— ❌ 发现缺陷，✅ 同日已修复

三章全完成后，`weeklyQuest` 才出现，三条任务实测（修复前）：

| 任务 | 修复前 | 判定 |
|---|---|---|
| 巡游三地（回访 3 个不同地点） | 3/3 ✅ | 可完成 |
| 回声邮局（收集 2 个奇遇回声） | 1/2 ❌ | 奇遇 35% 命中，偏难 |
| **伙伴灯火（回到灵伴签名地点 1 次）** | **0/1 ❌ 不可完成** | **缺陷** |

**根因**：8 只灵伴的签名地点**全部在第一章**（`SIGNATURE_BY_SPECIES` 的 `nodeId` 均为首章节点）。终章后 `activeChapter` 是第三章，`explore()` 的 `node.chapterId !== chapter.id` 检查会拒绝回访首章节点，实测返回：

```
explore(child, 'shadow-bridge', today, ...) →
{ error: '请先在当前章节完成这一段星路' }
```

即：**只要孩子走到终章，"伙伴灯火"这一条就永远点亮不了**，回访周常上限被锁死在 2/3（实测 1/3）。

#### 修复与验证（2026-09-13 当日完成）

改动 `lib/adventure.js` 两处：

1. `explore()`：三章全部完成后，允许回访**任意已访问**节点（跨章）；未完成三章时仍照旧拒绝。
2. `adventureView()`：终章后返回**全部已访问节点**作为可回访入口（而不是只返回当前章节点）。

修复后专项探针（走完三章 → 回访首章签名地点）：

```
campaignCompleted: true
可回访节点数: 21        （修复前只有 7 个：仅第三章节点）
签名地点: shadow-bridge
回访结果: 成功
weeklyQuest: 巡游三地 2/3✗ · 回声邮局 2/2✓ · 伙伴灯火 1/1 ✓
```

回归：主回归 **225/0**、星图 **60/0**，无新增失败。

## 五、分组反馈（按年龄段）

### 7-9 岁（家长主导型）
- 首章 100% 完成，回访意愿最高（平均 7.7 次），是最健康的一档
- 但 30 天内只有 2/6 走完三章——主要卡在"有效日"不够，不是意愿问题
- 残页 17.2/21：中间漏掉的日子不补残页，符合"不做补打卡"的设计

### 10-12 岁（自主型）
- 三章完成 3/6，好于低龄档（参与更稳定），回访 1.5 次
- 严格模式家庭在此档：实测严格惩罚只在连续缺席 ≥3 天时触发一次，符合家长预期

### 13-14 岁（易流失档）
- **30 天内 0/6 完成三章，平均回访 0.3 次** —— 这是最需要关注的一档
- 残页仅 13.7/21：内容没被看到，等于主线白写
- 建议：这一档单独延长试玩周期至 60 天，并考虑在第二章后加入"回来看看"的轻提醒
