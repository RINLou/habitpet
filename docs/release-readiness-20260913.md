## APK 出包方式

新增 [`scripts/build-apk.ps1`](../scripts/build-apk.ps1)。它会从当前 `public/` 建立全新暂存包，并把正式 API 地址只写入暂存的 `runtime-config.js`，因此不会把测试隧道写入源码或误打旧资源。它也兼容 WorkBuddy 留存的便携式工具链，并将全部 Android 工具输入临时复制至纯英文路径，避开旧版 `aapt` 的中文路径故障。

```powershell
$env:HABITPET_KEYSTORE_PASSWORD = '仅在当前终端会话设置'
.\scripts\build-apk.ps1 `
  -ApiBase 'https://正式后端.example.com' `
  -ToolchainRoot 'C:\path\to\build-tools' `
  -JdkRoot 'C:\path\to\jdk' `
  -KeystorePath 'C:\path\to\release.keystore' `
  -KeyAlias '发布别名'
```

2026-09-13 已生成并检查未签名验证包：包含 `classes.dex`、`index.html`、运行时 API 配置文件及 185 个动画资源，且 APK 元信息为 `com.habitpet.app` / `灵汐大陆` / `1.0.0-beta.1` / minSdk 24 / targetSdk 33。验证包固定指向无效占位地址，**不可安装或分发**。历史 `webview-apk/aligned.apk` 也是旧资源，不能分发。

## 发布前仍需完成的外部条件

1. 将当前分支的 `server.js` 部署到正式 HTTPS 后端，确定 `ApiBase`；旧 WorkBuddy 地址缺少三章冒险接口，不能使用。完成重启、重启后数据持久化和真机联网验证。
2. 用已验证的 WorkBuddy 工具链和既有发布签名库运行出包脚本；执行 `apksigner verify`，再在至少一台 Android 真机安装验证。
3. 选择发布渠道：建议先发给明确同意的 10–20 个家庭做 45–60 天受控试玩，而不是直接公开上架。
4. 若上 Google Play 或面向不特定儿童公开：补齐隐私政策、家长同意与数据处理说明；当前跨家庭好友没有双家长批准，证据照片也没有自动保留期，这两项应先关闭或补齐。Google Play 对含儿童受众的应用要求准确声明受众、隐私政策和数据安全信息，并适用 Families 政策；对未满 14 周岁的中国儿童个人信息，需取得监护人同意。 

## 本次不做的事

- 不上传任何商店、不部署生产服务器、不生成或保管用户的发布签名密钥。
- 不把模拟数据写成“真人试玩”。
- 不在孩子端开启收费或运营方商业化；商业化接口只继续保持预留状态。
