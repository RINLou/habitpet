# 灵汐大陆品牌与世界观 MVP 工作日志

## 本批目标

把技术合并版从“养成好习惯”功能应用的外观，推进为《灵汐大陆》的可识别游戏体验：统一品牌、首次启动讲清世界观、让灵伴选择和日常反馈使用同一套心光叙事。

## 已完成

- 主标题统一为“灵汐大陆”，副文案为“让每个好习惯，点亮一颗星”。
- 更新网页 title、PWA name/short_name、登录页品牌和玩法说明入口。
- 新增首次启动序章：浊气侵蚀大陆 → 好习惯产生心光 → 愿望球召唤灵伴 → 从第一步开始冒险。
- 序章可跳过、只自动展示一次，并可从“灵汐大陆玩法”入口重播。
- 为 8 只普通灵伴补充地域、性格与职责标签，并显示在选宠页和宠物首页。
- 非焰狼没有独立逐帧资源时，升级/回归仍会触发通用 CSS 反馈；焰狼继续使用已验证的精灵动画。未伪称其他物种已经完成独立逐帧动画。
