# 《灵汐大陆》可玩性与持续吸引升级计划

## 状态

**分阶段实施中。** 本轮已落地 P0-A/P0-B/P0-C 与 P1-A 的相册入口；本文剩余 P1-A 的内容扩充、P1-B Boss 复盘和 P2 第二章仍是后续排期。当前已实现内容以 `docs/adventure-mvp-log.md` 为准。

## 依据与结论

本计划合并三类证据：

1. 15 日家长/孩子双视角模拟试玩：D1-D7 能完成首章，D8 可回访，D9 漏投喂不丢章节；灵狐签名事件和随机奇遇能带来短期新鲜感；Lv1 Boss 已可首战获胜。
2. 新一轮关卡/留存设计复审：D7 后只有重复回访，没有新的可见目标、选择或收集结算，形成内容悬崖。
3. 当前产品约束：冒险不改 XP、亲密度、账本和家庭零花钱；商业化保持关闭；不把儿童回访设计成打卡惩罚。

核心判断：下一轮不是扩一张地图，而是让孩子在 D8-D30 每天仍能回答“我今天可以选什么、为什么想回来、留下了什么”。

## 北极星体验

- 孩子：30 秒内知道今天能做什么；漏一天知道不会失去章节；完成后得到可展示、可回看的故事收藏。
- 家长：10 秒内知道孩子走到哪里、最近有什么发现、是否需要一句鼓励；无需每天审批或催促。
- 设计：选择创造变化，收藏承接变化，数值不绑架变化。

## 升级路线

### P0-A：第二周“回访任务板”

**目标**：把毕业后的重复点击改成一周内有明确、可选择、非数值的目标。

每个自然周生成 2-3 个任务，只显示给已完成首章的孩子；每天仍保持一次投喂后的冒险行动。

首批任务模板：

- `巡游三地`：本周回访 3 个不同地点。
- `回声邮局`：收集 2 张回声明信片（随机奇遇或节点剧情提供）。
- `伙伴灯火`：回到当前灵伴的签名地点，留下 1 盏灯。

完成奖励只点亮相册格、称号或装饰性印记；不得发 XP、亲密度、家庭积分或运营方权益。

验收：

- D8 后首页显示本周 2-3 个目标、进度和可选地点。
- 同一周的地点选择不能全部自动落在同一个节点；无选择时给出两个推荐地点。
- 完成任务不改变现有任何数值或账本。
- 章节毕业、漏一天和跨设备重启后任务状态可恢复。

### P0-B：温和缺席提示与 Boss 复盘

**目标**：消除“漏一天就失败”和“打不过不知道怎么办”的两类挫败。

- 未投喂态和探索拦截统一补充：`今天先照顾灵伴；章节进度会保留，明天从原来的地方继续。`
- Boss 失败反馈根据实际状态给一条下一步建议：升级/下一技能解锁/和家人联手；不使用羞耻或惩罚文案。
- Boss 开战前显示“本场为什么适合现在挑战”的简短预览；Lv1 不承诺必胜，但目标是首次挑战可理解、可重试。

验收：

- 漏一天后章节节点与已完成天数零回退。
- Boss 失败页至少有一条可执行建议，且不要求付费、刷资源或邀请陌生人。
- 7-12 岁试玩者能复述“漏一天会怎样”和“打不过下一步怎么办”。

### P0-C：家长端“冒险脉冲”摘要

**目标**：让家长看见进度，但不把轻冒险变成每日审核任务。

在家长总览每个孩子卡片增加一行摘要：

`首章 7/7 · 最近：月见潮汐 · 发现：月光纸灯 · 下一步：本周还差 1 个地点`

仅提供“看看/鼓励”的轻入口；不新增批准、扣分、催办、目标强制修改。

验收：

- 家长端可读章节进度、最近节点、最近奇遇/签名事件和任务下一步。
- 没有把运营方价格、会员、订单字段带到孩子端或摘要中。
- 多个孩子的摘要互不串数据。

### P1-A：星光相册与小分支

**目标**：把已经写入数据的发现记录变成可见收藏，并为回访提供低风险自主选择。

- 孩子端新增“星光相册”：节点故事、签名事件、随机奇遇、任务印记按地点/灵伴分类；显示“已收集/待发现”。
- 回访时给一个不影响数值的两选一分支，例如“帮谁带路 / 留下哪种记号”；结果写入相册。
- 初批每个节点至少有 4 条可轮换剧情，每只普通灵伴至少有 2-3 个关系片段；避免只扩成长文案。

验收：

- 相册可离线读取缓存，服务端状态返回后正确合并。
- 同一地点连续回访不连续展示同一句故事。
- 选择只影响叙事、相册和装饰性状态，不影响数值和战斗强度。

### P1-B：Boss 可理解性，不做战力膨胀

**目标**：让对战从“重复点唯一技能”变成轻度学习，而不是变难。

- 对战前展示对手特点、推荐行动和下一个技能解锁条件。
- 对战后保留最近三场复盘：胜负、使用技能、下一条建议。
- Lv8 前不新增第二套装备、随机掉落、体力或数值货币；策略差异优先来自技能效果和目标选择。

验收：

- Boss 首战完成率目标 70%-85%，而非 100%。
- 首战失败孩子中，至少 60% 在 72 小时内再次尝试。
- 失败提示不改变亲密度、章节、收藏或家庭奖励。

### P2：第二章只在验证后启动

**启动条件**：先证明回访任务板和相册有效，再制作新的 7 日地图与逐帧内容。

建议第二章采用“不同路线汇聚同一终点”的轻分支结构：孩子选择 2 条主题路线之一，但不造成错过核心内容或战力差。

## 数据与试玩门槛

数据只做家长侧匿名聚合，默认不建立儿童画像。上线小样本先完成真实试玩：每个年龄段（7-9、10-12）至少 5 名孩子和 5 位家长。

| 指标 | 验收线 |
|---|---:|
| D7 完成者在 D8 再进入冒险 | ≥55% |
| D8-D15 人均完成回访/收藏行动 | ≥4 次 |
| 回访仅集中在一个地点的比例 | <45% |
| 冒险后打开相册或任务板的比例 | ≥50% |
| 漏一天后 48 小时内恢复探索 | ≥60%，章节零回退 |
| 家长查看摘要后仅阅读/鼓励、不改规则 | ≥80% |

## 明确不做

- 不新增付费、广告、会员入口、战力售卖或随机抽取。
- 不做连续签到断档惩罚、随机事件数值奖励、限时排行或强制社交。
- 不让回访任务要求家长审核；它应是孩子自主的轻探索。
- 不在 P0/P1 直接扩第二张地图；先解决 D7 后的内容悬崖。

## 建议交付顺序

1. P0-A 回访任务板与持久化/离线测试。
2. P0-B 缺席提示、Boss 预览和失败复盘。
3. P0-C 家长端冒险脉冲摘要。
4. P1-A 相册、小分支和第二批故事内容。
5. P1-B Boss 轻策略反馈。
6. 真实小样本试玩达标后，再立项第二章。
