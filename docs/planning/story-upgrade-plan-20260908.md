# 《灵汐大陆》第一章叙事升级计划

## 状态

**三章叙事 MVP 已实施；逐节点独立剧情演出仍待评估。**

本计划只升级剧情、演出和叙事承接，不改变现有 2D 卡通+轻 RPG 的视觉方向，不新增付费内容，不调整核心数值平衡。本批由 Codex 直接实现；后续大规模美术与第二章内容再视排期拆分。

## 一、设计判断

当前的主要年龄门槛不是 2D 美术，而是故事深度：日常行动、地图节点、灵伴签名事件和世界观之间仍然像“功能模块”，没有形成一条让孩子想追下去的连续主线。

目标是让 7–9 岁孩子看得懂，让 10–14 岁孩子愿意追剧情、猜谜团、做选择。

## 二、第一章核心命题

### 章节标题

**第一章《熄灭的七盏灵灯》**

### 一句话梗概

灵汐大陆的七盏灵灯正在依次熄灭。孩子与新召唤的灵伴沿着七日星图寻找失落的心光，最终发现：真正让灵灯重新点亮的，不是一次完美表现，而是愿意在中断后重新开始。

### 玩家身份与目标

- 玩家是刚完成立愿的“新任守光者”。
- 灵伴不是等待喂养的宠物，而是拥有记忆、性格和判断的同行者。
- 每次真实完成习惯，都会为当天的灵灯补回一束心光。
- 七日结束时，玩家要决定把最后一束心光交给哪一处需要帮助的地方；选择影响章节结语、相册记录和后续回访内容，不影响战斗数值。

### 核心冲突

浊气并非单纯的“坏人攻击”。它来自大陆居民对“只允许完美、不能重新开始”的误解。这个冲突可以承载成长主题，也能避免把漏打卡写成失败或羞耻。

## 三、七日主线重写

| 日程 | 现有节点 | 剧情功能 | 玩家可见变化 |
|---|---|---|---|
| D1 | 星海关口 | 召唤灵伴，发现第一盏灵灯熄灭 | 选择灵伴回应方式，记录第一条相册线索 |
| D2 | 赤曜荒原 | 遇见携带残光的迷路信使 | 选择先帮助信使还是先追踪浊气，形成不同短对白 |
| D3 | 月见潮汐 | 得知七盏灯共享同一段被删去的记忆 | 解锁“旧星历”第一片残页 |
| D4 | 影桥回廊 | 影子复述玩家过去未完成的约定 | 允许玩家承认中断并选择重新点灯 |
| D5 | 翠雨林地 | 灵伴的签名事件与主线产生交集 | 记录灵伴的个人动机，不改变属性 |
| D6 | 磐石隘口 | 低压 Boss：浊灵守着最后一枚灯芯 | 战前展示机制和推荐行动，失败后留下线索 |
| D7 | 星心圣所 | 点亮七灯，揭开“浊气来自失望的回声” | 选择章节结语，开启毕业后的回访支线 |

每一天控制在 2–5 分钟，主线文本不超过 3 屏；完整背景放入可选的“星历残页”，避免低龄玩家被长文本阻塞。

## 四、灵伴角色弧线

每只普通灵伴保留现有签名事件，并补齐三段关系节点：

1. **初见**：它为什么回应这个孩子的愿望。
2. **分歧**：它对“坚持”和“完美”的看法与玩家不同。
3. **确认**：它见证玩家重新开始，形成一句只属于这只灵伴的章节结语。

焰狼不再作为唯一主角；其他七只灵伴应拥有同等重要的叙事入口，只在地域、语气、象征意象上区别，不做数值强弱区分。

## 五、选择与回访

### 选择原则

- 选择改变对白、线索顺序、相册条目和回访地点。
- 不改变 XP、亲密度、战斗强度、家庭奖励和毕业资格。
- 不设置“正确答案”；每条路线都能在七日内完成主线。

### 回访结构

毕业后保留三类可追踪内容：

- **旧星历**：补齐首章未读的世界观残页。
- **灵伴来信**：查看不同灵伴对同一事件的解释。
- **灯下回声**：回访当天选择的地点，触发一段 20–40 秒的短事件。

## 六、演出要求

不依赖更换美术风格，优先用现有 2D 资源完成：

- 地图节点点亮、连线流光、灵灯熄灭/复燃。
- 角色立绘轻微位移、表情帧、对话框节奏变化。
- Boss 战前 3 秒剪影和一句动机台词。
- 章节结尾用“七盏灯—灵伴—玩家选择”三段式回顾。

动画只服务于叙事转折，不为每句对白单独制作动画；每个节点最多 1 个关键演出和 1 个回访演出。

## 七、年龄层表达

| 年龄 | 默认体验 | 可选深度 |
|---|---|---|
| 7–9 岁 | 短句、图标、明确目标、即时反馈 | 自动播放星历残页 |
| 10–12 岁 | 完整对白、人物动机、轻推理 | 主动阅读残页和分支记录 |
| 13–14 岁 | 伏笔、关系变化、结局差异 | 查看旧星历、灵伴来信和隐藏线索 |

## 八、验收标准

- 新玩家首 10 分钟能复述“灵灯为什么熄灭、我现在要做什么”。
- 完成 D7 后，孩子能说出至少一个灵伴的动机，而不是只记得它的数值。
- 10–14 岁试玩者中，至少 60% 能主动打开一条星历残页或回访事件。
- 漏一天后剧情不回退，文本明确支持“重新开始”。
- 选择只改变叙事收藏，不改变核心经济、战斗和家庭奖励。
- 360px 视口下对白、选择按钮、章节结语无溢出；可跳过但不强制跳过。

## 九、实施顺序

1. 先锁定第一章剧情大纲、七日对白节拍和三种章节结语。
2. 再为八只灵伴补齐三段关系节点。
3. 接入选择记录、星历残页和回访事件的数据结构。
4. 用现有 2D 逐帧资源制作节点转场与章节结算演出。
5. 完成 7–9、10–12、13–14 三组小样本试玩，再决定是否启动第二章。

## 明确不做

- 不把游戏改成写实或高龄向美术。
- 不用复杂战斗数值掩盖剧情不足。
- 不让随机事件决定主线结局。
- 不增加付费、广告、会员或抽卡。
- 不在本方案通过前让 WorkBuddy 修改主线代码。
