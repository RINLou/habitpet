# 一、核心功能与设计目标

## 1.1 产品是什么

| 项 | 内容 |
|---|---|
| 产品名 | 好习惯宠物大冒险 / HabitPet（品牌世界观：**灵汐大陆**） |
| 形态 | PWA（可安装）+ 安卓 WebView APK「养成好习惯」 |
| 技术栈 | Node 零运行时依赖后端 + 原生 JS 前端 + IndexedDB 本地优先 |
| 服务对象 | 孩子（养灵伴）+ 家长（审核、规则、奖励）双端 |
| 一句话世界观 | **孩子的每一个好习惯，都会在另一个世界化作光。** |
| 第一法则 | **灵汐不认说出来的话，只认做到的事。**（真实做到才有心光） |

## 1.2 双端功能地图

**孩子端**
- 立愿 → 从愿望球召唤灵伴（8 只原创灵伴，九大族裔）
- **每日投喂**（19:00–21:00，每天一次）→ 心光 +1，连续 7 天灵脉灵潮
- **申报成就**：考试 / 默写出门测 / 自豪的事（可附照片留影封印）→ 家长鉴定
- **星图冒险**：三章 21 日主线，每日节点 + 剧情 + 无优劣选择 + 章节结语
- **灵斗**：兄妹 1v1 / 单人 Boss / 兄妹联手 Boss / 好友约战（每日限 5 场）
- **许愿池兑换**：用羁绊之力换零花钱、游戏时间券、实物
- **星光相册 / 星海图鉴**：节点故事、签名事件、奇遇、任务印记

**家长端**
- PIN 锁（守护人印记）+ 密保问题（秘语）
- 待审核收件箱（看佐证照片、通过/驳回）
- 手动加减分、浊气（投诉）记录、奖励目录与核销
- 规则配置：分值、每周上限、每日对战上限、**投喂时段**、缺席模式、假期模式、休眠茧
- 月之潮汐（月度结算）/ 毕业巡礼（学期结算）
- **冒险脉冲摘要**（P0-C）：一行看懂孩子走到哪、最近发现、下一步

## 1.3 核心数值 ↔ 世界观映射

| 系统 | 世界观 | 规则 |
|---|---|---|
| 经验值 XP | **心光** | 投喂 + 申报 + 灵斗；学期末随毕业清零 |
| 亲密度 | **羁绊之力** | 兑换奖励的货币；每月 1 号（朔月）重置 |
| 投诉扣分 | **浊气** | 家长可驱散（退分留痕）；整月无浊气 +100 清白祝福 |
| 暂停计 | **休眠茧** | 时光冻结：不进食、不断连击、不清空 |
| 灵伴阶段 | 愿望球 Lv1 / 幼体 Lv5 / 成体 Lv12 / 觉醒 Lv20 | 觉醒 +3% 羁绊；毕业入图鉴 |

## 1.4 本轮（2026-09-13）交接增量

- 主线由 1 章扩为 **三章 21 日**：第一章《熄灭的七盏灵灯》、第二章《月影回廊的回声》、第三章《星海归航》
- 完成一章后孩子**主动点亮下一章**；已完成章节可回访；**同日不能借切章多探索一次**
- 章节选择/星历/结语/相册按章节永久保存；`SCHEMA_VERSION` 升至 **9**，旧存档自动迁移
- 主线选择、章节切换、回访**全部不改** XP / 亲密度 / 战斗 / 账本 / 家庭奖励
- `test:anim` 改为独立服务启动器；静态资源缓存 `hp-v19`
- 测试：主回归 **225/0**、星图 **60/0**、动画 **68/0**

## 1.5 设计目标（从文档提炼的 7 条）

1. **真实行为驱动**：心光只认做到的事，说出来的不算（家长鉴定为阀门）
2. **冒险是核心循环**：从"五个功能页"变成有地图、有章节、有选择的连续主线
3. **叙事不绑架数值**：选择只改对白/线索/相册/回访，不改经济、战斗、奖励
4. **漏一天不惩罚、不羞耻**：温和缺席（默认只提醒）、进度零回退、唤醒免费、无羞耻文案
5. **长期留存有目标**：D8–D30 每天仍能回答"我今天可以选什么、为什么想回来、留下了什么"
6. **家长轻介入**：10 秒看懂进度，只给"看看/鼓励"，不新增审批与催办
7. **儿童安全优先**：孩子端不出现运营方商业化；跨家庭社交与照片走最小化原则

**北极星体验**：孩子 30 秒内知道今天能做什么；家长 10 秒内知道孩子走到哪里。

## 1.6 当前状态（务必记住）

- ✅ 已实现：三章主线、八灵伴三段关系线、回访任务板、星光相册、家长冒险摘要、温和缺席 + 免费唤醒
- ⏸ 待试玩确认后才允许：**部署云端 / 重打 APK / 合入 main**
- ⚠️ 上线前专项未闭环：跨家庭好友、照片保留期、儿童隐私合规

# 二、试玩家庭安排方案

## 2.1 这次试玩要验证什么

对齐两份规划的验收标准（`story-upgrade-plan` 8 条 + `retention-upgrade-plan` 6 条）：

| # | 验收项 | 验收线 |
|---|---|---|
| 1 | 首 10 分钟能复述"灵灯为什么熄灭、我现在要做什么" | 定性复述，≥80% 家庭 |
| 2 | D7 后能说出至少一个灵伴动机（而非只记得数值） | ≥80% |
| 3 | 10–14 岁主动打开残页 / 回访事件 | ≥60% |
| 4 | 漏一天后剧情不回退 | **100%（零回退）** |
| 5 | 选择不改核心经济 / 战斗 / 家庭奖励 | **100%（红线）** |
| 6 | 360px 对白、选择按钮、结语无溢出 | 100% 机型 |
| 7 | D7 完成者在 D8 再进入冒险 | ≥55% |
| 8 | D8–D15 人均回访 / 收藏行动 | ≥4 次 |
| 9 | 回访只集中在一个地点的比例 | <45% |
| 10 | 冒险后打开相册或任务板 | ≥50% |
| 11 | 漏一天后 48h 内恢复探索 | ≥60% |
| 12 | 家长看摘要后仅阅读/鼓励、不改规则 | ≥80% |

## 2.2 家庭筛选标准

**纳入条件**
- 孩子按**周岁**分三档：**7–9 / 10–12 / 13–14**
- 每档 **5 个家庭**（共 15 个家庭，15–22 名孩子，15 位家长）
- 家长能每日陪观察 2–5 分钟，并填 4 次问卷（D0/D7/D21/D30）
- 家庭有可执行"每日 19:00–21:00 投喂"的作息（投喂窗窄，需在知情书中说明）

**结构配额（在 15 个家庭内分配）**

| 维度 | 配额 | 验证目的 |
|---|---|---|
| 多孩家庭 | ≥3（其中三孩≥1） | 兄妹联手 Boss、家长摘要不串数据、图鉴 |
| 单孩家庭 | ≥6 | 主线单线体验 |
| 安卓 WebView APK | ≥8（含低端机 ≥2） | APK 副本、性能、360px |
| iOS Safari PWA | ≥5 | PWA 安装、离线缓存 |
| 桌面浏览器 | ≥2 | 家长端大屏体验 |
| 旧版本用户 | ≥2 | **schema v9 迁移**（旧第一章存档） |
| 断网/弱网场景 | ≥3 | 离线投喂 + 本地缓存不丢、恢复后对齐 |
| 严格缺席模式 | ≥1（家长主动开启） | strict 模式休眠茧 + 免费唤醒是否可理解 |

**排除条件**
- 家长从事游戏/教育软件行业（专业偏差）
- 近 3 个月参加过同类产品调研
- 无法保证连续 30 天参与的家庭

**最小可行档（招募不足时）**：每档 3 个家庭（共 9 个），但必须覆盖：多孩 ×1、安卓 APK ×1、iOS ×1、断网 ×1、旧版本迁移 ×1。低于 9 个家庭时，指标 7–12 只能作定性参考，不建议作为上线依据。

## 2.3 排期（30 天）

> 选期建议：避开期中/期末考试周与法定长假（假期模式会切换申报目录，干扰主线数据）。

| 阶段 | 日程 | 孩子做 | 家长做 | 重点验收 |
|---|---|---|---|---|
| **W0 准备** | D-3 ~ D0 | — | 签署知情同意、装设备、填基线问卷 | 招募完成度、设备覆盖 |
| **D0 启程** | 第 1 天 | 注册→绑定→立愿→召唤灵伴→完成首次投喂+探索 | 陪同计时、记录"首 10 分钟" | **验收 1**（首 10 分钟复述）、首启契约 |
| **W1 第一章** | D1–D7 | 每日投喂+D1…D7 探索（2–5 分钟/天） | 每日一句话日记 | **验收 2、5、6** |
| **D8–D10 回访** | 第 9–11 天 | 点亮第二章前，先做回访任务板 + 相册 | 填 D7 问卷（延至 D8） | **验收 7、9、10** |
| **D9 漏投喂** | 第 10 天 | **刻意不投喂一天** | 记录孩子反应与文案 | **验收 4、11**（零回退 + 48h 恢复） |
| **W2 第二章** | D11–D17 | 点亮第二章，推进 7 日 | 观察切章是否困惑 | 切章理解度、同日防多探索 |
| **W3 第三章** | D18–D24 | 点亮第三章，推进 7 日 + 终章结语 | 填 D21 问卷 | 三章结语分布、长期新鲜度 |
| **W4 观察期** | D25–D30 | 自由回访 / 相册 / Boss | 填 D30 问卷 | **验收 8、12**、D30 留存 |
| **复盘** | D31–D33 | — | 数据汇总 + 家庭回访 | 出结论，决定部署/合 main |

**刻意设计的观察点**（不要避开，这些是重点）：
- D9 漏投喂（验证零回退与文案是否让孩子安心）
- 至少 1 个家庭开启**严格缺席模式**（验证休眠茧 + 免费唤醒可理解）
- 至少 3 个家庭做一次**断网投喂**（验证离线后不丢、恢复后对齐）

## 2.4 数据采集方式（合规前提）

- **不新增儿童画像埋点**（文档明确：数据只做家长侧匿名聚合，默认不建立儿童画像）
- 优先**直接读取服务端已有状态**即可算出验收线，无需新埋点：
  - `adventure.discoveries[].playedOn` → 回访频次、地点集中度（验收 8、9）
  - `adventure.visited` / `chapterDay` / `completedDays` → 零回退（验收 4）
  - `weeklyQuest.tasks[].progress` → 任务板使用（验收 10）
  - D8 是否产生新 discovery → 验收 7
- 家长侧：**每日一句话日记**（<1 分钟）+ 4 次结构化问卷
- 增设一个**"卡住了"即时上报按钮**（孩子/家长都能点），收集定性阻塞点

## 2.5 试玩纪律（DEVLOG 明令）

- 试玩确认前：**不部署云端、不重打 APK、不合入 main**
- 每个家庭发一份《家长须知》：说明这是测试版、数据可能重置、投喂窗时间、如何反馈
- 试玩范围：本次先跑第一章；每章毕业后的下一天点"点亮下一章"继续
