# 灵汐大陆 · 商业化设计纲要（讨论稿 v1）

> 2026-09-08 与老板对齐的结论。供 Codex 在下一阶段开发中参照——特别是
> 品牌替换（步骤1）、世界地图/图鉴（步骤3）、统一动画协议（步骤4）三个埋钩子点。
> 状态：**讨论对齐稿，未进入开发**；落地前以老板最新拍板为准。

## 一、总纲（一句话）

**付费的是家长，使用的是孩子。所有变现设计只有一条铁律：孩子端永远不出现「钱」。**

变现主线不是游戏内购，而是「家长为孩子的成长数据买单」：

- 孩子（用户）：免费玩，零支付入口
- 家长（客户）：审核、看报告、做付费决策
- 孩子端产生的习惯数据/心光成长 = 家长付费的价值来源

## 二、四条收入线（按优先级）

### ① 家庭会员订阅（主力）

- **免费给足核心**：1 只宠物、习惯打卡、投喂进化、家长审核、基础周报
- **会员解锁**：
  - 多孩子家庭（二孩三孩 = 最强付费动机）
  - 完整世界地图 / 全图鉴
  - 家长深度周报（习惯滑坡预警、时段效率分析）
  - 专属动画、专属区域、专属皮肤
- **定价锚点**：¥88/年 或 ¥12/月，**按「家庭」收，不按孩子收**
- 设计前提：周报必须先免费做出粘性，深度分析再收费

### ② 外观/皮肤内购（补充）

- 宠物皮肤、场景主题、进化特效，¥1-3 一个，一次性买断
- 心智路径：**家长下单 → 孩子收到惊喜**（送礼感，不引导孩子索购）
- 技术依赖：统一动画协议（步骤4）完成后，换皮即新商品，边际成本极低
- 孩子侧表达：一律走「许愿 → 家长确认」流程，把购买欲转化为亲子互动

### ③ 奖励商城（免费功能，留存的发动机）

- 家长承诺真实奖励（玩具/出游/零花钱），App 只做心愿单 + 进度账本
- **红线：绝不碰真实资金托管**（支付牌照级风险，不进不碰）
- 价值链路：孩子坚持打卡 → 家长看到改变 → 续费订阅。它是 ① 的转化中枢

### ④ B 端班级版（差异化渠道）

- 幼儿园 / 托管班 / 培训机构：老师布置习惯任务、家长收报告
- 定价：¥2000-6000 / 园所 / 年
- 渠道优势：太原本地 BD 人脉地推，成本远低于线上投流；一签带几十个家庭进场

### 明确不做

- 孩子端广告
- 抽卡 / 盲盒式宠物获取
- 战绩排行榜付费
- 理由：儿童产品口碑即命；且均触碰未成年人保护敏感区

## 三、合规红线（上线前必须立好）

| 项 | 要求 |
|---|---|
| 支付 | 孩子端零支付入口；所有价格/按钮只在家长端；孩子侧仅「许愿单」 |
| 儿童个人信息 | 监护人同意书 + 独立儿童隐私政策（个保法 + 儿童个信网络保护规定） |
| 资质 | 软著 + ICP 备案（建议云端部署前后办理）；定位「家庭教育工具」，不卖课程 → 不碰办学许可 |
| 宣传 | 禁用「提高成绩」类效果承诺（广告法） |
| 商标 | 「灵汐大陆」尽早查 35/41/42 类并注册，趁早占坑 |

## 四、与下一阶段开发顺序的衔接（不改 Codex 的顺序，只埋钩子）

| Codex 步骤 | 商业化埋点 |
|---|---|
| 1 品牌替换 | 同步查「灵汐大陆」商标；品牌资产统一为后续 IP 化打底 |
| 2 序章 | 序章结尾自然引出「世界地图待探索」的期待感（为地图铺路，不提钱） |
| 3 世界地图/图鉴 | **设计时直接按「免费区 3 块 + 会员区」划分**，别做完再切；图鉴留「？」占位=会员内容位 |
| 4 统一动画协议 | 协议即皮肤工厂；`contract.json` 模式推广到 8 只动物，为内购备弹药 |
| 5 世界观话术 | 奖励商城表述用世界观语言（心愿清单/月神馈赠），规避商业化气息 |
| 6 部署+APK | 部署前后办软著/ICP；上线后进「免费观察期」 |

## 五、上线后的验证节奏

1. **先免费跑 1-2 个月**：种子家庭 = 自家 + 亲友 + 本地 1-2 个幼儿园试点
2. **看三个数再定收费**：
   - 周留存（孩子端是否持续打开）
   - 家长周报打开率（付费价值感知）
   - 多孩子家庭占比（订阅转化主力盘）
3. 数据撑得住 → 上订阅 + 内购；撑不住 → 先修产品，不变现
