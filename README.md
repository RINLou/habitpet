# 灵汐大陆 · HabitPet

> **一句话世界观**：孩子的每一个好习惯，都会在另一个世界化作光。
> **第一法则**：灵汐不认说出来的话，只认做到的事。

把孩子的好习惯变成养灵伴的正反馈：完成作业「投喂」心光，灵伴升级、进化、觉醒；每日投喂后走进星图冒险，用三章 21 日的故事找回熄灭的灵灯；月底用**羁绊之力**兑换零花钱或奖励。守护人（家长）负责鉴定真实、守坛与净化浊气。

## 一、灵汐大陆速览

在现实的倒影里有一片叫**灵汐**的大陆，照亮它的是现实世界飘来的**心光**。心光是这里唯一的粮食、唯一的火、唯一的钱。三大力量构成全部机制：

| 力量 | 对应旧称 | 说明 |
|---|---|---|
| **心光** | 经验值 | 喂给灵伴吃、让它升级进化的力量。来源：每日作业投喂、鉴定的成就、灵斗切磋 |
| **羁绊之力** | 亲密度 | 孩子与灵伴的情感联结，储存在羁绊圣坛，是这里的"货币"，可兑换现实奖励 |
| **浊气** | 投诉/扣分 | 老师或长辈传来的坏消息，会侵蚀羁绊；守护人可驱散（取消投诉退分） |

**月之潮汐**：羁绊圣坛每逢朔月（每月 1 号）自动清空重注——不是惩罚，是大陆的自然法则。整月没有浊气入侵的家庭，朔月之夜会得到月神的**清白祝福**（无投诉奖 +100）。

> 完整设定见 [`WORLDVIEW.md`](WORLDVIEW.md)。

## 二、功能概览

### 孩子端

- 在**愿望球**前立下学期之愿，呼唤一只灵伴降临（Lv1 愿望球 → Lv5 幼体 → Lv12 成体 → Lv20 觉醒）
- 每日完成作业「投喂」心光，连续打卡 7 天额外奖励
- **星图冒险（三章 21 日主线）**：每日投喂后出发一次，找回熄灭的七盏灵灯
  - 第一章·熄灭的七盏灵灯 / 第二章·月影回廊的回声 / 第三章·星海归航
  - **选择只改变故事，不改变数值**；**漏一天不惩罚**，进度保留、明天从原处继续
  - 收集残页、图鉴、灵伴关系线（初见—分歧—确认）与章节结语
  - 三章完成后开启**本周回访任务**（巡游三地 / 回声邮局 / 伙伴灯火），可回访任意走过的地点
- 提交考试、默写/出门测、自豪的事（可拍照佐证）等待守护人鉴定
- 与兄弟姐妹 1v1 切磋，或联手挑战 Boss
- 用羁绊兑换零花钱、游戏时间券等奖励
- 查看进化、五维雷达图、星光相册、图鉴、兄弟姐妹榜
- 可安装为 PWA，另有安卓 WebView 壳「养成好习惯」

### 守护人（家长）端

- 印记（PIN）保护 + 敏感操作二次确认
- 待鉴定收件箱（查看佐证照片、通过/驳回）
- 手动加减、记录浊气（投诉）并可在月度结算前撤销
- 奖励目录管理、兑换「已发放」确认
- 编辑分值规则、每周加分上限、每日对战上限、**投喂时段**
- 月度结算、学期结算、暂停计、假期模式、**缺席模式**
- 一键复制月报（冒险摘要 + 账目）发微信

## 三、缺席与唤醒（默认温和）

| | 温和模式（**默认**） | 严格模式（守护人显式开启） |
|---|---|---|
| 满 3 天没投喂 | 只提醒「我在等你」 | 一次性 −10 羁绊 |
| 满 5 天没投喂 | 只提醒 | 灵伴进入**休眠茧** |

- 温和模式下：**不扣羁绊、不进入休眠茧、章节与收藏零回退**
- **唤醒一律免费**：不降级、不扣羁绊、不清除任何永久收藏
- 缺席不锁死核心玩法，不使用羞耻文案
- 生病暂停 / 假期模式会冻结计时

## 五、核心数值模型

- **零花钱公式**：下月零花钱 = 基础额（守护人可设）+ 本月现金兑换锁定的加成
- **对战永不消耗羁绊**：输赢只影响心光与五维
- **主线探索永不改变数值**：剧情与数值完全解耦

## 六、快速开始

### 1. 本地体验

```bash
git clone https://github.com/yourname/habitpet.git
cd habitpet
npm install      # 仅安装 pm2 等开发/部署工具，后端零运行时依赖
node server.js
```

浏览器打开 `http://localhost:3000`：

1. 注册守护人账号
2. 添加孩子，生成绑定码
3. 在孩子手机上打开同一地址 → 「我是孩子」→ 输入绑定码 → 立愿选灵伴

### 2. 生产部署

准备一台 Ubuntu 20.04+ 服务器，把代码放到 `/opt/habitpet`：

```bash
cd /opt/habitpet
DOMAIN=yourdomain.com EMAIL=your@email.com bash deploy/deploy.sh
```

无域名则去掉 `DOMAIN` 参数，仅通过 IP 访问（不推荐长期使用）。

## 七、对战机制

简化自经典掌机回合制 RPG：

- **五维**：攻击、防御、体力、敏捷、智慧
- **属性相克**：火→草、水→火、电→水 等（0.5 / 1 / 2 倍伤害）
- **STAB**：使用与灵伴同属性技能，伤害 ×1.5
- **伤害公式**：`伤害 = ((2×等级/5+2) × 技能威力 × 攻/防 / 50 + 2) × STAB × 克制 × 随机(0.85~1.0)`
- **模式**：兄妹 1v1、单人 Boss、兄妹联手 Boss
- **Boss 难度按技能解锁台阶分段标定**（Lv1-7 / Lv8-14 / Lv15+），避免出现"必败断崖"

## 八、配置说明

复制 `.env.example` 为 `.env`：

```bash
PORT=3000
DATA_DIR=./data
PHOTO_DIR=./data/photos
BACKUP_DIR=./data/backups
JWT_SECRET=你的随机长字符串
```

首次启动后，在守护人端「系统设置」里修改：基础零花钱、投喂时段（默认 19:00–21:00）、每周上限、每日对战上限、缺席模式、学期开学日期等。

## 十二、安全与隐私

- 守护人密码使用 scrypt 哈希存储
- 佐证照片仅守护人 token 可读，单独落盘，不进入 git
- 数据目录、照片目录已加入 `.gitignore`
- 儿童不产生独立账号画像；社交功能（跨家庭好友、相册分享）尚未开放
- 建议生产环境启用 HTTPS 并配置防火墙（仅开放 80/443/SSH）
