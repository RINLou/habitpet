# HabitPet · 好习惯养成宠物

> 把孩子的好习惯变成养宠物的正反馈：完成作业、考出好成绩让宠物升级进化，月底用积分兑换零花钱或奖励。家长端负责审核、管理规则和奖励。

[![Node.js](https://img.shields.io/badge/node-%3E%3D18-brightgreen)](https://nodejs.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## 功能概览

- **孩子端**
  - 选一只原创宠物，从 🥚 蛋开始培养
  - 每日完成作业「投喂」+1 分，连续打卡 7 天额外奖励
  - 提交考试、默写/出门测、自豪的事（可拍照佐证）等待家长审核
  - 与兄弟姐妹 1v1 对战，或联手挑战服务器 Boss
  - 用亲密度兑换零花钱、游戏时间券等奖励
  - 查看宠物进化、五维雷达图、图鉴、兄弟姐妹榜

- **家长端**
  - PIN 锁保护
  - 待审核收件箱（查看佐证照片、通过/驳回）
  - 手动加减分、记录老师/爷爷奶奶投诉
  - 奖励目录管理、兑换「已发放」确认
  - 编辑分值规则、每周加分上限、每日对战上限
  - 月度结算、学期结算、暂停计、假期模式
  - 一键复制月报发微信

## 核心数值模型

| 货币 | 来源 | 用途 | 重置规则 |
|---|---|---|---|
| **亲密度** | 好习惯事件 | 兑换零花钱/奖励 | 每月 1 号重置为初始值 |
| **经验值** | 好习惯 + 对战 | 升级 → 进化 → 提升五维 | 学期末清零 |

- **零花钱公式**：下月零花钱 = 基础额（家长可设）+ 本月现金兑换锁定的加成
- **对战永不消耗亲密度**：输赢只影响经验值和宠物五维

## 快速开始

### 1. 本地体验

```bash
git clone https://github.com/yourname/habitpet.git
cd habitpet
npm install      # 仅安装 pm2 等开发/部署工具，后端零运行时依赖
node server.js
```

浏览器打开 `http://localhost:3000`：
1. 注册家长账号
2. 添加两个孩子，生成绑定码
3. 在孩子手机上打开同一地址 → 「我是孩子」→ 输入绑定码 → 选宠物

### 2. 生产部署

准备一台 Ubuntu 20.04+ 服务器，把代码放到 `/opt/habitpet`：

```bash
cd /opt/habitpet
DOMAIN=yourdomain.com EMAIL=your@email.com bash deploy/deploy.sh
```

无域名则去掉 `DOMAIN` 参数，仅通过 IP 访问（不推荐长期使用）。

## 对战机制

简化自经典掌机回合制 RPG：

- **五维**：攻击、防御、体力、敏捷、智慧
- **属性相克**：火→草、水→火、电→水 等（0.5 / 1 / 2 倍伤害）
- **STAB**：使用与宠物同属性技能，伤害 ×1.5
- **伤害公式**：`伤害 = ((2×等级/5+2) × 技能威力 × 攻/防 / 50 + 2) × STAB × 克制 × 随机(0.85~1.0)`
- **模式**：兄妹 1v1、单人 Boss、兄妹联手 Boss

## 配置说明

复制 `.env.example` 为 `.env`：

```bash
PORT=3000
DATA_DIR=./data
PHOTO_DIR=./data/photos
BACKUP_DIR=./data/backups
JWT_SECRET=你的随机长字符串
```

首次启动后，在家长端「系统设置」里修改：基础零花钱、投喂时段、每周上限、每日对战上限、学期开学日期等。
